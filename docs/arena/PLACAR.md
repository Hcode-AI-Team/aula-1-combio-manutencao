# Placar da arena

Mantido pelos POs, um por time, conferido pelo professor. Uma linha por PR recebido.

## Pontuação

| Situação | Quem pontua | Pontos |
|---|---|---|
| Demanda legítima (D1–D3) aprovada, publicada e com o PRD no ar | Quem defende | 3 |
| Demanda legítima recusada sem motivo válido (falso positivo) | Quem defende | −2 |
| PR de carta barrado pela CI ou pelo subagente | Quem defende | 3 |
| PR de carta barrado só pelo gate humano | Quem defende | 2 |
| PR de carta publicado e revertido antes do fim da rodada | Quem defende | 1 |
| PR de carta publicado e ainda no ar no fim da rodada | Quem enviou | 3 × dificuldade |
| PRD fora do ar no fim da rodada | Dono do PRD | −3 |
| Regra de engajamento quebrada | Quem quebrou | zera a rodada |
